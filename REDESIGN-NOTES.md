# NextStep Digital website refresh

This archive contains the refreshed Astro website source.

## Homepage changes
- Reworked the homepage into a navy, electric-blue and white visual system.
- Removed the hero statistics row (client count, projects delivered and years of experience).
- Removed the “Watch Our Story” control.
- No client testimonials section is included.
- Added Creative Work, How We Work, Digital Toolkit, Why NextStep and FAQ sections.
- Kept the existing service offering and social media package prices from the supplied project.
- Kept the contact details and WhatsApp destination from the supplied project.
- Added responsive layouts, scroll-reveal motion and mouse-following 3D tilt on service cards.

## Existing pages and assets
The original About, Services, Pricing, Blog/Articles and SEO pages, content, media assets, Astro configuration and dependency lockfile are retained. The navigation has been refreshed and includes the Blog link.

## Build
Run `npm install`, then `npm run build` to validate and build the project. A production build could not be run in this environment because dependency installation did not complete (network/package registry timeout).
